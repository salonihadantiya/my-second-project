# Simple Text Editor App
A GUI-based desktop Text Editor application built using python (Thinker) that allow users to create, open, save, and manage text files seamlessly.

## Features
* **New File:** Create a new document.
* **Open File:** open existing text file from your system.
* **save file:** save edited content to your desired location.
* **Exit:** Easily close the application .

## HOW to Run
1. Ensure python is installed on your machine.
2. Run the application file using:
```bash
python appdeveloper.py
